전체 구조(개념)

PP7 MacBook에서 1) 베뉴 내장 빔으로 메인 자막을 내보내고, 2) 우리가 가져가는 컨피턴스용 빔/스크린에는 필요 시 별도의 출력(미러링 또는 확장)을 사용한다.
운영 안전을 위해: “연결→화면 인식→PP7 출력 설정→리허설” 순서를 고정한다.

설정 원칙(안정성)

  • [원칙1] 출력 포트/젠더를 최소 구성으로: USB-C → HDMI(권장) 또는 HDMI 직결
  • [원칙2] 발표/예배 중에는 알림/절전 OFF, 방해금지 ON
  • [원칙3] PP7은 “Audience(관객)” 화면만 빔으로, “Stage(스테이지)” 화면은 운영자 모니터로
  • [원칙4] 해상도/주사율 불일치가 가장 흔한 문제 → 1080p 60Hz 기준으로 맞추기
  • [원칙5] 문제가 생기면: 케이블→젠더→디스플레이 설정→PP7 스크린 할당 순서로 복구
1) 현장 준비물(젠더/케이블) “이게 없어서 망함” 방지
  • USB-C → HDMI 어댑터(Apple Silicon 대비)
  • HDMI 케이블 2개 이상(메인 + 컨피턴스)
  • (필요 시) HDMI 연장 / 리피터(거리 길면)
  • (상황 따라) USB-C → DisplayPort / Lightning 젠더(아이패드/폰 입력 필요 시)
젠더/HDMI/연장선/멀티탭 준비 완료
팁: HDMI는 생각보다 “접촉불량”이 잦아서 예비 1개는 필수.
2) 물리 연결: 베뉴 빔 + 컨피턴스 빔 2출력 시나리오

시나리오 A (가장 단순/안정): 메인 자막은 베뉴 빔 1개만 사용. 컨피턴스 빔은 예비.

시나리오 B (2출력): 베뉴 빔 = Audience / 컨피턴스 빔 = Stage(또는 미러)로 운용.

연결 순서(권장)
  1. 맥북 전원 연결 + 방해금지 ON
  2. USB-C → HDMI 어댑터를 맥북에 연결
  3. HDMI #1 → 베뉴 빔(또는 벽 패널 입력)
  4. HDMI #2 → 컨피턴스 빔(우리가 가져온 빔)
  5. 빔 전원 ON → 입력 소스(HDMI1/HDMI2) 선택
베뉴 빔에 화면 출력 확인
컨피턴스 빔(우리 빔)에 화면 출력 확인(사용 시)
3) macOS 디스플레이 설정 미러링/확장/해상도
  1. macOS 시스템 설정 → 디스플레이로 이동
  2. 외부 디스플레이(빔)가 1개/2개로 잡히는지 확인
  3. 권장: Audience를 메인 빔으로 확장(미러링 해제), 운영자는 맥북 화면 사용
  4. 해상도: 기본은 1920×1080, 주사율 60Hz 권장
디스플레이가 정상 인식 + 1080p 기준으로 안정화
문제 시: 케이블 재연결 → 빔 입력 소스 확인 → 해상도 낮춰보기(720p) → 재부팅(최후)
4) ProPresenter 7 설정 Audience/Stage Screen 할당
  1. PP7 실행 → Screens(또는 환경설정) 메뉴
  2. Audience Screen을 “베뉴 빔(외부 디스플레이)”로 할당
  3. (선택) Stage Screen을 “컨피턴스 빔”으로 할당하거나, 운영자 맥북 화면으로 둠
  4. 테스트: 슬라이드 2~3개 넘기며 글자 크기/여백 확인
Audience/Stage 화면 할당 완료 + 테스트 출력 OK
권장: 글자 크기 크게(현장 시야), 흰 글자+검은 그림자/반투명 박스 등 가독성 우선.
5) 운영 프로토콜(예배 중) 실수 방지
  • 예배 시작 전: 첫 슬라이드 준비 + 전체 화면(Full Screen) 상태 확인
  • 곡 전환: 다음 곡 1절 미리 띄워두고 Go Live
  • 설교: 본문/제목/포인트 슬라이드 순서 고정
  • 문제 발생: “검정 화면” 또는 “배경 화면”으로 즉시 전환하는 비상 슬라이드 준비
비상(블랙/배경) 슬라이드 준비 + 단축키 확인
6) 트러블슈팅 현장 30초 복구
A) 빔에 “No Signal”
  1. 빔 입력 소스가 HDMI로 맞는지
  2. HDMI/젠더 재삽입(끝까지)
  3. macOS 디스플레이에서 외부 모니터 인식되는지
B) 화면이 나오는데 PP7 자막만 안 나옴
  • PP7에서 Audience Screen 할당이 바뀌었는지 확인
  • Full Screen/Output On 상태 확인
C) 글자가 너무 작거나 잘림
  • 해상도 1080p로 고정
  • PP7 테마/세이프마진 조정
