전체 구조(개념)

Wing Compact를 FOH(믹싱석)에 두고, 무대에는 DL16(AES50-A), SD8(AES50-B)를 배치한다.
SD8은 악기 인풋 전용으로 사용하고(무대 악기 라인 가까이), DL16은 무선/보컬/기타 필요한 라인을 받는다.
모니터: 악기는 P16-M(ULTRANET), 싱어는 P2(유선 IEM)로 보낸다.

설정 원칙(안정성)

  • [원칙1] FOH에서 나가는 메인 출력은 Wing의 MAIN L/R(또는 Matrix)로 관리
  • [원칙2] SD8/DL16 출력에 “PA를 직접 물려도” 되지만, 출력 라우팅을 문서화해서 헷갈림 방지
  • [원칙3] 모니터는 “필요 최소 믹스” + “라벨링” (누가 어느 버스를 쓰는지)
  • [원칙4] AES50은 CAT5e/6 이더넷 케이블처럼 생겼지만 전용 오디오 네트워크. 공유기/인터넷과 혼동 금지
  • [원칙5] 문제 시 복구 순서: 전원→AES50 링크→라우팅→게인→PA
1) 설치 전 체크(전원/케이블/라벨) 10분
멀티탭/연장선 확보(FOH / 무대 / PA 전원 분리)
XLR/전원/AES50/ULTRANET 케이블에 테이프 라벨(A/B/IN/OUT 표시)
무선 수신기/안테나(Phenyx) 설치 위치 확보: 무대 앞/FOH 근처, 금속/벽 뒤 피하기
팁: “안테나/무선 수신기”는 랙 뒤에 숨기면 수신률이 급락할 수 있음.
2) AES50 연결(DL16/SD8) CAT5e/6 케이블

AES50 케이블은 일반 랜선처럼 보이지만, 오디오 네트워크로 사용한다. 공유기/스위치에 꽂지 말 것.

  1. Wing Compact AES50-A ↔ DL16 (CAT5e/6)
  2. Wing Compact AES50-B ↔ SD8 (CAT5e/6)
  3. DL16/SD8에서 AES50 포트 LED/상태가 “LINK/OK”인지 확인
AES50-A ↔ DL16 링크 OK
AES50-B ↔ SD8 링크 OK
링크 안 잡히면: 케이블 교체 → 포트 재삽입(딸깍) → DL16/SD8 재부팅 → Wing 재부팅(최후)
3) ULTRANET(P16) 연결 악기 P16-M 분배

P16 시스템은 Wing의 ULTRANET에서 나온다. 여기서 P16-D(Distributor)로 분배 후 각 P16-M에 CAT5e/6로 연결.

  1. Wing Compact ULTRANET → P16-D IN (CAT5e/6)
  2. P16-D의 OUT 포트들 → 각 악기 자리 P16-M (CAT5e/6)
  3. P16-M 전원(어댑터) 연결
Wing ULTRANET → P16-D 연결 완료
각 P16-M 수신/전원 OK(레벨 미터 움직임)
P16-D→P16-M 선도 “랜선처럼 생긴 CAT5e/6”. DMX랑 혼동 주의.
4) 싱어 유선 IEM(P2) 연결 XLR/AUX

P2는 유선 인이어 앰프. 보통 Wing의 Aux/Bus 출력을 XLR/TRS로 받아서 P2에 넣는다.

  • 추천: Wing에서 Bus(모니터 믹스) 1~2개를 만들고 싱어에 배정
  • 물리 연결: Wing의 XLR OUT(또는 스테이지박스 OUT) → (XLR) → P2 입력
  • 가능하면 P2는 보컬 자리 근처(케이블 짧게), 바닥은 가퍼로 고정
P2 입력 라인 연결 + 볼륨 최소에서 시작(귀 보호)
P2는 “메인 L/R”를 넣지 말고, 꼭 “싱어 모니터 버스”를 넣어야 함.
5) 무선 마이크(Phenyx 8ch) + 안테나 시스템 수신기→DL16

무선 수신기 출력은 일반적으로 XLR 밸런스 아웃. 이 출력을 DL16의 인풋으로 받으면 FOH에서 채널로 뜬다.

  1. Phenyx 수신기 + 안테나 분배/연장 장치 설치(안테나는 무대 전면 시야 확보)
  2. 수신기 채널별 XLR OUT → DL16 IN (예: IN1~IN8)
  3. Wing에서 해당 입력이 들어오는지 레벨 미터 확인
  4. 채널 이름 라벨: “WL HH1~7 / WL Headset” 등
무선 수신기 → DL16 인풋 연결 완료
각 무선 마이크 “말하면” 미터 반응 확인
중요: 무선은 “송신기/수신기” 주파수/그룹/채널이 맞아야 하며, 리허설 전에 배터리 확인.
6) 메인/프론트필/서브(우퍼) 연결 출력 라우팅

원칙은 “FOH에서 컨트롤 가능한 출력”을 PA로 보내는 것. 장비 구성에 따라 메인 스피커가 “메인+우퍼 일체형 2개”라면, 보통 메인 L/R만 보내도 된다.

  • 메인 PA: Wing MAIN L/R → (XLR) → 스피커 L/R
  • 프론트필(있다면): Matrix 1/2 또는 Bus로 별도 출력 → 프론트필 앰프/스피커
  • 서브(분리형일 때): Matrix/Sub Out → 서브 입력 (크로스오버는 스피커/프로세서 설정에 따름)
메인 PA L/R 연결 완료 (볼륨 0에서 시작 → 천천히 올림)
프론트필(있다면) 별도 라우팅/출력 확인
“SD8 OUTPUT → PA”도 기술적으로 가능하지만, 출력 소스가 Wing에서 무엇으로 라우팅되는지 문서화/고정해야 혼선이 없다.
7) 클릭/토크백 운영 예배 안정용
  • 클릭: 드러머/악기 IEM에만 보내고 메인으로는 절대 안 나가게 (버스/매트릭스 체크)
  • 토크백: FOH 토크백 마이크를 “모니터 버스”에만 라우팅
  • 안전: 클릭/토크백은 라벨링 + 뮤트 버튼 위치 고정
클릭이 IEM에만 들어가고 메인 PA에는 안 나옴
토크백이 모니터에만 들어가고 메인에는 안 나옴
8) 빠른 트러블슈팅 증상별 60초 복구
A) DL16/SD8 인풋이 안 들어옴
  1. AES50 케이블 뽑았다 다시 꽂기(딸깍)
  2. Wing에서 AES50-A/B 링크 상태 확인
  3. 스테이지박스 재부팅
B) P16-M에 아무것도 안 나옴
  • ULTRANET → P16-D → P16-M 케이블 확인
  • Wing에서 ULTRANET 채널 할당이 비어있지 않은지 확인
C) 메인 PA가 안 나옴
  • 스피커 볼륨/전원 확인
  • Wing MAIN L/R 미터 확인
  • 출력 라우팅이 올바른지(메인/매트릭스)
현장 규칙: 문제가 생기면 “작은 것부터” (전원/케이블/뮤트/페이더) 체크 후 라우팅으로.
