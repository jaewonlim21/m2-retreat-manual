🎛️ M2 수련회 조명 매뉴얼 (Lightkey + Wireless DMX + TD-17 킥 트리거)

목표: (1) 씬 5개 운영 (2) 킥 FX “화이트 팍!” (3) 씬은 계속 돌아가도록 레이어 방식 유지
🔎
체크 0%

전체 구조 요약

Mac(Lightkey) → ENTTEC DMX USB Pro → Wireless DMX TX ⇒(무선)⇒ RX-1(Wash 체인), RX-2(Spot+Haze 체인)
킥 트리거는 TD-17 USB MIDI → Mac → Lightkey에서 MIDI Learn로 FX 실행.

설정 원칙 (현장 안정성)

  • [원칙1] 킥 FX는 Intensity만 건드린다 (색/팬틸트/고보 변경 금지)
  • [원칙2] Duration 80–150ms (추천 100ms)
  • [원칙3] 중복 방지(Cooldown) 120–200ms
  • [원칙4] Haze는 킥 연동 금지(별도 ON/OFF)
  • [원칙5] MIDI가 죽어도 씬 단축키(1~5)로 예배 운영 가능하게 백업
1) 설치 전 체크리스트 전원/안전/장비 상태
전원/멀티탭/연장선 확보(과부하 방지: 조명 전원 몰빵 금지)
바닥 케이블은 가퍼테이프로 고정(넘어짐 방지)
TX 1 / RX 2 / ENTTEC / 조명(Wash3 Spot2 Haze1) 전원 ON 확인
팁: 조명 전원은 최소 2개 멀티탭으로 분산(무빙+헤이즈 전류 피크 대비)
2) 물리 연결: FOH(조명석) Mac–ENTTEC–TX
  1. MacBook 전원 연결(충전기 필수)
  2. ENTTEC DMX USB Pro를 Mac에 직결(허브 지양)
  3. ENTTEC DMX OUT → Wireless DMX TX(DMX 케이블 1개)
  4. TX 전원 ON, 가능한 테이블 위/높은 위치 배치
주의: TX를 금속 프레임/앰프/랙에 바짝 붙이면 링크가 불안정해질 수 있음
3) 물리 연결: 무대 RX 2대 + 데이지체인
RX-1 (Wash 체인)
  1. RX-1 전원 ON
  2. RX-1 DMX OUT → Wash1 DMX IN
  3. Wash1 OUT → Wash2 IN → Wash2 OUT → Wash3 IN
RX-2 (Spot + Haze 체인)
  1. RX-2 전원 ON
  2. RX-2 DMX OUT → Spot1 IN → Spot1 OUT → Spot2 IN
  3. Spot2 OUT → Hazer IN (마지막)
DMX 규칙
  • OUT → IN 방향 준수
  • Y 분기 금지(직렬만)
  • 가능하면 마지막에 Terminator(없어도 대부분 OK)
4) 무선 DMX 링크(채널/그룹 맞추기) TX/RX 동일 채널

무선 DMX는 TX와 RX가 같은 채널/그룹이어야 신호를 받음. 제품에 따라 버튼 방식 또는 DIP 스위치 방식.

버튼(채널/컬러) 방식
  1. TX의 CH/MODE 버튼을 눌러 채널(색/번호)을 고정
  2. RX-1도 같은 채널로 맞춤
  3. RX-2도 같은 채널로 맞춤
  4. RX의 Signal/Link LED가 고정/빠른 점멸이면 성공
  5. 안 되면 TX/RX 모두 전원 OFF→ON 후 반복
DIP 스위치 방식
  1. TX의 DIP ON/OFF 패턴을 정함
  2. RX-1/2도 완전히 동일하게 맞춤
  3. 전원 OFF→ON(재부팅) 후 링크 확인
링크 실패 시: RX를 TX 가까이(1~2m) 가져와 시도 → 되면 거리/장애물 문제. TX를 높게.
5) DMX 주소(Address) 설정 겹치면 100% 꼬임

모드(채널 수)를 정확히 몰라도 주소를 넉넉히 띄우면 안전.

  • Wash1: 001, Wash2: 021, Wash3: 041
  • Spot1: 061, Spot2: 081
  • Hazer: 101
모든 조명에서 Start Address가 위 값으로 세팅됨
조명 메뉴에서 MENU → DMX → Address(Addr)로 들어가 설정하고 ENTER로 저장.
6) Mac 기본 세팅(현장 안정화) 절전/알림/USB
전원 연결 + 잠자기/화면꺼짐 최소화(현장에서는 사실상 OFF)
방해금지(DND) ON / 알림 OFF
USB 액세서리 연결 허용 팝업 뜨면 허용
ENTTEC는 허브보다 직결이 가장 안정적. 인식 안 되면 포트 변경→재연결→재부팅(최후).
7) Lightkey: DMX Output 설정 ENTTEC 선택이 핵심
  1. Lightkey 실행
  2. Preferences/Settings → DMX Output
  3. Interface에서 ENTTEC DMX USB Pro 선택
  4. Universe = 1
  5. Output Enable(출력) ON
Lightkey에서 ENTTEC가 보이고 Output이 ON
8) Lightkey: Patch(조명 등록) + 단품 테스트 한 대씩 켜보기
  1. Patch/Fixtures에서 Wash 3 / Spot 2 / Haze 1 추가
  2. Universe=1, Address=001/021/041/061/081/101 입력
  3. Live 화면에서 한 대씩 Intensity 올려 반응 확인
Wash 3대 각각 단품 테스트 OK
Spot 2대 각각 단품 테스트 OK
Hazer DMX 반응 OK(딜레이 있을 수 있음)
전부 안 되면: Output/ENTTEC → 주소 일치 → TX/RX 링크 → DMX 방향(OUT→IN) 순서로 점검.
9) 씬 5개 만들기 + 단축키 운용자 운영 핵심

씬은 많을수록 실수. 5개면 예배 전체 커버 가능.

  • 1 PRE: 밝게/환영
  • 2 WORSHIP: 따뜻한 톤 + 무빙 최소
  • 3 FAST: 더 밝게 + 무빙 약간
  • 4 SERMON: 화이트 고정(눈부심 최소)
  • 5 PRAYER: 어둡게 + 백/사이드
씬 1~5에 단축키 1~5 할당 완료
MIDI가 죽어도 씬 단축키만으로 예배 운영 가능해야 함(백업).
10) TD-17 킥 트리거: USB MIDI 연결 킥=화이트 팍!
  1. TD-17 USB(B) → Mac USB로 연결(가능하면 안정적인 케이블/허브)
  2. macOS Audio MIDI Setup에서 TD-17 인식 확인(선택)
  3. Lightkey에서 MIDI Input 장치로 TD-17 선택
Lightkey에서 TD-17 MIDI 입력이 잡힘
11) 킥 FX 만들기 (씬 위 레이어) Intensity only + 100ms

목표: 씬은 유지되고, 킥이 들어오면 전체(Wash+Spot) Intensity만 100ms 올라갔다가 원복.

  • FX 이름: KICK_WHITE_POP
  • 대상: Wash ALL + Spot ALL (Haze 제외)
  • 변경값: Intensity 100% (가능하면 색은 건드리지 않거나 White)
  • Duration: 100ms
  • Cooldown: 120~200ms(가능한 경우)
KICK_WHITE_POP 생성 완료
MIDI Learn로 킥에 매핑
  1. FX/큐의 External Controls 또는 MIDI Assign 열기
  2. MIDI Learn 클릭
  3. TD-17에서 킥 1번 밟기
  4. 이제 킥 입력 → FX 실행
킥 밟으면 “화이트 팍!” 동작 확인
킥이 너무 자주 터지면: (1) TD-17 킥 감도/스레숄드 조정 (2) Velocity 필터(가능 시) (3) Cooldown 늘리기.
12) KICK MODE ON/OFF (안전장치) FAST에서만 ON

가장 중요한 사고 방지 장치: 설교/기도 때 킥이 터지면 분위기 깨짐.

  • KICK MODE ON: FAST 찬양 시작할 때 켬
  • KICK MODE OFF: FAST 곡 끝나면 끔 (Sermon/Prayer는 무조건 OFF)
운용자가 KICK MODE를 쉽게 켜고/끄는 방법(버튼/단축키/토글)을 확보함
구현은 환경마다 다르지만, 원칙은 “킥 입력을 받더라도 OFF일 땐 FX 실행이 안 되게” 만드는 것. (가장 쉬운 백업은: OFF일 때는 MIDI Assign을 잠시 Disable/해제)
13) 운영 프로토콜(예배) 운용자/드러머 역할
운용자
  • 씬 단축키 1~5로 분위기 전환
  • FAST 들어갈 때 KICK MODE ON, 끝나면 OFF
  • Haze는 별도 운영(킥 연동 금지)
드러머
  • 킥을 “후렴 첫 박/드랍/강세”에서 의도적으로
  • 하이햇은 너무 잦아 비추천(눈 피로/과자극)
14) 트러블슈팅(증상별) 현장 즉시 복구
A) 전체가 안 됨
  1. Lightkey Output ON + ENTTEC 선택 확인
  2. ENTTEC USB 재연결
  3. TX/RX 링크 확인(채널 동일?)
  4. DMX 체인 OUT→IN 확인
B) 일부만 됨
  • 해당 라인(RX-1 또는 RX-2) 링크/전원 문제 가능
  • 해당 장비 Address/Mode 불일치 가능
C) 킥이 씬을 바꿈
  • MIDI가 FX가 아니라 Scene에 매핑된 상태 → FX에만 매핑
